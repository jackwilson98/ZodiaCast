# 🔮 ZodiaCast

Welcome to **ZodiaCast** – your cosmic companion that delivers a unique, randomly generated astrology-inspired message every time you run it.

---

## 🌌 What is ZodiaCast?

ZodiaCast is a JavaScript-based message generator that crafts short astrology-style predictions. Each message is dynamically composed from multiple randomized components to deliver fun, mystic, and unique fortunes with every execution.

---

## ✨ Example Messages

- *Capricorn, today brings clarity and connection.*
- *Leo, the stars reveal a challenge worth facing.*
- *Pisces, a mysterious energy surrounds your path.*

---

## 🧪 How It Works

Each message is generated from three arrays:
1. **Signs** – Zodiac signs.
2. **Openings** – How the message starts.
3. **Closings** – A fortune, vibe, or cryptic advice.
